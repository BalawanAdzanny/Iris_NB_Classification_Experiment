# Iris_NB_Classification_Experiment
Notebook ini berisi eksperimen klasifikasi menggunakan algoritma Naive Bayes pada dataset Iris. Tujuannya adalah untuk membangun model yang mampu mengenali spesies bunga berdasarkan fitur panjang dan lebar sepal serta petal. Eksperimen mencakup pelatihan, prediksi, dan evaluasi performa model.
